# Project Journal

This folder is the running presentation record for the project.

## Purpose

- keep a chronological explanation of what was built
- document technical decisions and assignment alignment
- make final presentation preparation easier at the end of the term

## Files

- `01_chronology.md`: timeline of the project from the first backend setup until now
- `02_assignment_alignment.md`: mapping between teacher requirements and current implementation
- `03_m2_safe_roadmap.md`: future expansion plan that keeps the latest M2 assignment intact

## Update Rule

From this point onward, every meaningful change in the project should also update this journal.

- add the date
- explain what changed
- explain why it changed
- mention affected files
- mention any setup or testing steps
